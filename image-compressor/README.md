# 圖片壓縮工具

完全在瀏覽器本機處理的多檔圖片壓縮 Starter；不會上傳圖片，也不需要 API、帳號或金鑰。

## 使用方式

1. 直接開啟 `index.html`。
2. 點擊或拖放 PNG、JPEG、WebP 圖片。
3. 調整壓縮品質後執行壓縮。
4. 比較原始／輸出大小，個別或批次下載。
5. 使用「清除」移除目前工作區資料。

## 隱私與限制

- 圖片只在目前瀏覽器分頁中處理，不會傳送到伺服器。
- JPEG／WebP 品質控制依瀏覽器 Canvas 編碼能力而定。
- PNG 不保證一定縮小；複雜或已最佳化的圖片可能產生較大檔案。
- GIF 動畫不會保留動畫影格。

## Fork → Remix → Publish

1. Fork 或複製此專案。
2. 修改標題、配色、預設品質或輸出格式。
3. Commit 後使用 GitHub Pages 發布。
4. 發布後用自己的圖片實測下載結果，不要只看畫面。

## Level 1–3 任務

- **Level 1：**更換配色、標題與預設壓縮品質。
- **Level 2：**新增輸出格式選擇或壓縮比例摘要。
- **Level 3：**加入尺寸縮放、批次命名與壓縮前後預覽比較。
