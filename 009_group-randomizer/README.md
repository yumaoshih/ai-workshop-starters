# 分隊！一鍵分組器

貼上人員名單，選擇分成幾組或每組幾人，即可產生適合現場公布的公平隨機分組。每人只會出現一次，組間人數差不超過一人；所有資料只留在瀏覽器內。

## 主要功能

- 即時統計有效姓名與重複姓名
- 支援「分成幾組」與「每組幾人」
- Fisher–Yates 隨機洗牌與平均分配
- 彩色分隊公布板與短促揭曉動畫
- 再抽一次、複製結果、全螢幕公布與列印
- 本機儲存名單及設定，不需網路或帳號

## 本地使用

直接用瀏覽器打開 `index.html`（`file://`）即可，不需安裝套件、API 或網路連線。

## Fork → Remix → Publish

1. Fork 或複製此目錄。
2. 替換預設名單、隊伍命名或活動配色。
3. 以靜態網頁託管工具發布（選做）。

## 工作坊任務

### Level 1

- 改成班級、營隊或公司活動的預設名單
- 替換隊伍名稱與識別色

### Level 2

- 加入隊長鎖定功能
- 允許抽籤後拖曳交換成員

### Level 3

- 避免連續兩輪出現相同組合
- 加入平衡分組條件與 CSV／圖片匯出
