# 今天吃什麼？美食輪盤

純靜態、可離線使用的美食抽選工具。以大型美食輪盤的抽選節奏為功能參考，視覺延續同專案喝水記錄器的明亮青綠風格。

## 本地使用

1. 打開 `index.html`。
2. 在「步驟 1」多選台式、日式、泰式、越式、韓式等分類；分類列可用觸控左右滑、滑鼠拖曳，或按「更多分類」。
3. 在「步驟 2」點擊「幫我決定」，等待輪盤減速並揭曉結果。
4. 不滿意可「再轉一次」，也能複製搜尋詞或直接開啟 Google 地圖查找。
5. 需要新增或修改內容時，再展開「自訂分類與料理」；至少保留兩道啟用中的料理才能旋轉。
6. 抽中料理後會顯示對應的手繪小圖；展開「過往美食筆記」可瀏覽五組口袋名單並把整組料理加入分類。
7. 點擊「恢復預設」回到 5 個分類、15 道預設料理。

## 資料與隱私

- 分類與料理只儲存在瀏覽器的 `food-wheel:v3`；舊版自訂選項會遷移為「我的料理」。
- 五組過往美食筆記整理自使用者提供的照片，包含飯食、麵食小點、異國風味、健康輕食、聚餐下午茶；店家營業與品項仍需在出發前確認。
- `assets/` 內的五張透明 PNG 是以 ImageGen 重新繪製的專案資產，不直接裁切拍攝投影畫面。
- 不載入遠端圖片、字體或 API；只有使用者點擊「Google 地圖查找」時才會開啟外部地圖頁面。
- 當次抽選結果不儲存。

## Fork → Remix → Publish

1. Fork 此資料夾。
2. 修改 `DEFAULT_GROUPS`、`COLORS` 或文案，做出自己的主題輪盤。
3. 直接以靜態網站方式發佈；公開部署仍依工作坊流程另行審核。

## Level 1–3 任務

- Level 1：替換預設料理與配色。
- Level 2：調整分類、料理內容、美食筆記與預設啟用組合。
- Level 3：延伸權重、店家收藏、抽選紀錄或可分享的輪盤設定。
