# 小小集點王 — 設計與互動規格

## 產品定位

「小小集點王」是一個由大人與孩子共同使用的本機集點工具。大人可以快速加減點數、設定獎勵與完成兌換；孩子則能立刻看懂目前累積、距離目標還差多少，以及現在可以兌換哪些獎勵。

產品的核心特色是「同一套集點功能，三套可自由切換的視覺主題」。切換主題只改變視覺語言與點數稱呼，不改變資料、按鈕位置、兌換規則或操作流程。

## 設計原則

1. **先看懂進度，再進行操作**：目前點數與下一個目標必須是第一視覺焦點。
2. **一個主要動作**：`＋1` 是畫面最醒目的操作；`−1` 是安靜但容易找到的修正操作。
3. **主題是外觀，不是三套產品**：所有主題共用相同資訊架構、控制項與資料模型。
4. **鼓勵而不評價孩子**：介面描述完成與累積，不使用「乖／不乖」、「成功／失敗」等標籤。
5. **孩子看得懂，大人操作得快**：主要文字使用繁體中文，觸控目標至少 44px，不依賴小字或顏色傳達狀態。
6. **維持 Workshop Starter 的低門檻**：純前端、本機儲存、無帳號、無 API、可直接修改 CSS 與本機素材。

## 共用畫面骨架

三個主題必須維持下列順序，避免切換後需要重新學習：

### 1. 頁首

- 顯示產品名稱與孩子名稱，例如「小安的小小集點王」。
- 右上角提供 `換風格` 按鈕。
- 孩子名稱可編輯；儲存後立即更新頁面標題並持久化。

### 2. 點數主視覺

- 以全頁最大數字顯示目前餘額。
- 同時保留不依賴主題的輔助文字，例如「目前有 7 點」。
- 主題可以將「點」視覺化為星星、貼紙或代幣，但不可改變實際數值。
- 點數變動後使用短暫動畫與 `aria-live` 公告新餘額。

### 3. 點數操作

- 主要按鈕：`完成一件事 ＋1`。
- 次要按鈕：`收回 1 點`。
- 餘額為 0 時，減少按鈕保持可見但停用。
- 加減點數後不開啟額外頁面，結果直接反映在主視覺、進度與獎勵狀態。

### 4. 下一個獎勵

- 顯示使用者目前選定的目標獎勵。
- 呈現獎勵名稱、成本、目前進度與「還差 N 點」。
- 已達成時改為「現在可以兌換」，並提供明確的 `兌換` 按鈕。
- 若尚未選擇目標，顯示「選一個想努力的獎勵」。

### 5. 獎勵清單

- 每項顯示名稱、所需點數與兌換狀態。
- 可負擔的獎勵使用有效 `兌換` 按鈕；不足時按鈕停用並顯示「還差 N 點」。
- 點擊獎勵本體可設為「下一個獎勵」，不會直接扣點。
- 兌換前顯示確認對話框，確認後才扣除點數。
- 清單下方提供 `編輯獎勵`，可新增、改名、調整成本與刪除獎勵。

### 6. 管理與重設

- 頁尾提供低強調但可見的 `重設集點板`。
- 重設前必須再次確認。
- 預設只重設點數與兌換進度，保留孩子名稱、獎勵清單與主題；確認視窗另提供「全部恢復預設」選項。

## 風格選擇器

### 入口

- 固定放在頁首右上角，文字為 `換風格`，不可只使用圖示。
- 首次使用可顯示一次簡短引導：「先挑一個喜歡的樣子」，並提供 `稍後再選`。

### 選擇面板

- 手機以底部面板呈現；桌面以置中對話框呈現。
- 面板標題為「選擇你的集點風格」。
- 三個主題以單選群組呈現，每項包含縮圖、主題名稱與一句描述。
- 點選主題即時預覽並立即保存，不需要再次確認。
- 關閉後回到原本捲動位置，點數與獎勵資料完全不變。

### 主題切換規則

主題可以改變：

- 色彩 tokens、背景紋理與插畫素材。
- 點數主視覺的呈現方式。
- 裝飾性圖示、分隔線與按鈕造型。
- 「點」的視覺別名，例如星星、貼紙、代幣。
- 符合主題的短句與鼓勵文案。

主題不可改變：

- 主要區塊順序與控制項位置。
- 加分、減分、設定目標、兌換與重設的行為。
- 孩子名稱、餘額、獎勵清單與目標資料。
- 控制項的 selector、語意角色與鍵盤操作。
- 負數防護與餘額不足時禁止兌換的規則。

## 三套內建主題

### 冒險地圖 `adventure`

- **概念**：每一點都是一顆星星，沿著路徑前往下一個獎勵。
- **主色**：暖米白、向日葵黃、葉綠、深靛藍。
- **主視覺**：星星路徑、目的地旗幟與小型動物旅伴插畫。
- **點數別名**：「星星」。
- **按鈕文案**：`完成一件事 ＋1 星`、`收回 1 星`。
- **氣質**：溫暖手繪、鼓勵探索，不使用遊戲戰鬥、排名或勝負符號。

### 今日貼紙簿 `sticker`

- **概念**：每一點都是一張收進貼紙簿的貼紙。
- **主色**：天空藍、珊瑚紅、奶油黃、薄荷綠。
- **主視覺**：貼紙收集區與撕紙／筆記本質感。
- **點數別名**：「貼紙」。
- **按鈕文案**：`完成一件事 ＋1 貼紙`、`收回 1 貼紙`。
- **氣質**：兒童活動本與蠟筆質感，適合 6～10 歲，但不使用幼兒化角色。

### 家庭小商店 `shop`

- **概念**：累積家庭代幣，選擇要存下來或兌換獎勵。
- **主色**：森林綠、番茄紅、芥末黃、再生紙米色。
- **主視覺**：代幣罐、票券與簡潔的獎勵展示架。
- **點數別名**：「代幣」。
- **按鈕文案**：`今天加一枚 ＋1`、`減少一枚 −1`。
- **氣質**：家庭文具店與孔版印刷感；不可呈現金錢、價格、購物車、賭博或商業促銷語氣。

## 共用視覺 Tokens

所有主題使用相同的語意 token 名稱，只替換值：

```css
--page-bg
--surface
--surface-subtle
--text-primary
--text-muted
--accent-primary
--accent-contrast
--accent-secondary
--success
--danger
--border
--focus
--radius-sm
--radius-md
--radius-lg
--shadow-soft
```

主題透過根節點的 `data-theme="adventure|sticker|shop"` 套用。核心元件不可直接寫死特定主題色。

## 狀態與資料規則

共用狀態至少包含：

```text
name: 孩子名稱
balance: 非負整數
rewards: [{ id, name, cost }]
targetRewardId: 目前目標獎勵，可為空
theme: adventure | sticker | shop
```

- `balance` 永不低於 0。
- 獎勵成本必須是大於 0 的整數。
- 兌換時再次檢查餘額，避免只依賴按鈕停用狀態。
- 刪除目前目標獎勵後，`targetRewardId` 清空。
- 主題選擇與集點資料分開保存；切換或重設主題不得覆寫餘額與獎勵。
- 所有資料只存於 namespaced `localStorage`，不發送網路請求。
- 升級現有版本時需讀取舊的 `rewards-v1:data`，遷移後保留原本名稱、餘額與獎勵。

## 核心互動流程

### 加一點

1. 使用者點擊主要加分按鈕。
2. 餘額加 1 並立即保存。
3. 主視覺播放不超過 400ms 的主題動畫。
4. 重新計算目標進度與所有獎勵的可兌換狀態。
5. 螢幕閱讀器公告「目前有 N 點」。

### 收回一點

1. 使用者點擊減少按鈕。
2. 餘額大於 0 時減 1；等於 0 時不執行。
3. 更新並保存所有相關狀態。

### 兌換獎勵

1. 使用者點擊可用的 `兌換`。
2. 對話框顯示獎勵名稱、成本與兌換後餘額。
3. 確認後扣除點數並保存。
4. 顯示簡短慶祝回饋；不使用全螢幕、不可略過的長動畫。
5. 若餘額在確認前已不足，停止兌換並公告原因。

### 切換主題

1. 使用者開啟 `換風格`。
2. 選擇任一主題並立即預覽。
3. 保存主題 key，畫面維持相同資料與操作位置。
4. 焦點返回 `換風格` 按鈕。

## 回應式

- 主要驗證尺寸為手機 390×844、桌機 1440×1024，另驗證 320px 窄螢幕。
- 手機使用單欄、全頁 App 畫布，不放入另一張置中的「手機卡片」。頁首黏附於頂端，主要加減分操作形成含安全區的底部操作列，所有內容保留足夠底部捲動空間。
- 手機對話框改為底部面板，使用頂部拖曳提示、圓角與底部安全區；桌機維持置中對話框。
- 960px 以上桌機改為左右工作區：左側是可黏附的孩子名稱、點數、插畫與加減操作；右側是目標進度、雙欄獎勵清單與管理操作。
- 760～959px 使用較寬的單欄平板畫布，避免在空間不足時過早分成兩欄。
- 獎勵清單可自然向下捲動；手機內容需透過底部 padding 避免被固定操作列遮擋。
- 320px 寬度下不得出現水平捲動。

## 無障礙

- 所有可操作元素皆可鍵盤操作並有清楚的 `:focus-visible`。
- 風格選擇器使用 `dialog` 與 `radiogroup` 語意，支援 Escape 關閉與焦點返回。
- 點數變化、兌換結果與錯誤狀態使用 `aria-live`，但避免重複公告裝飾性別名。
- 停用兌換需同時提供 `disabled`／`aria-disabled` 與文字原因，不能只靠灰色。
- 所有主題符合 WCAG AA 的文字對比；裝飾插畫提供空白替代文字。
- 支援 `prefers-reduced-motion`，停用路徑移動、貼紙彈跳與代幣掉落動畫。
- 不以紅綠作為唯一的成功／不足區別。

## 素材原則

- 三個主題可以使用各自的本機插畫，但尺寸與插槽位置必須共用。
- 不使用 emoji、文字符號、CSS 拼圖或手寫 SVG 假裝正式插畫。
- 主題素材需包含一致的裁切安全區，避免切換時造成版面跳動。
- 所有素材隨專案提供，離線開啟時不得缺圖。

## Workshop 改作層級

### Level 1 — 做出自己的第四套主題

- 修改語意色彩 tokens。
- 替換主題名稱、點數別名與本機插畫。
- 保持共用 DOM 結構與核心 JavaScript 不變。

### Level 2 — 客製獎勵與目標

- 完成新增、編輯、刪除獎勵。
- 讓使用者選擇下一個想努力的獎勵。
- 加入符合主題的兌換回饋。

### Level 3 — 擴充家庭使用情境

- 支援多位孩子與各自的點數、獎勵和主題。
- 加入可理解的點數歷史與撤銷。
- 支援匯出／匯入本機資料快照。

## 驗收邊界

- 三套主題下的核心操作與 selector 必須一致。
- 切換主題前後，孩子名稱、餘額、目標與獎勵清單完全相同。
- 0 點時不可減成負數。
- 餘額不足時不可兌換；足夠時扣除正確成本。
- 重新載入後保留資料與主題。
- `file://` 開啟時所有功能與素材皆可用，且沒有任何網路請求。
