# 孩子積分板

設定孩子名稱與獎項清單，藉由新增／減少積分鼓勵行為。如積分不足以兌換某獎項，該獎項不可兌換；同時阻止餘額低於零。

## 本地使用

用瀏覽器打開 `index.html`（`file://`），一切運作於瀏覽器內，不需網路。

## Fork → Remix → Publish

1. Fork 此目錄
2. 替換預設獎項、調整配色
3. 以靜態網頁託管工具發佈（選做）

## 任務

### Level 1
- 替換獎項清單與圖示文字
- 更換主題色

### Level 2
- 增加孩子切換（多孩子）
- 加入積分歷史小圖表

### Level 3
- 儲存獎項圖片為本地封存
- 匯入／匯出積分快照
