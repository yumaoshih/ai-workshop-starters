# 單字訓練器

新增「單字／意思」成對卡片，翻轉查看、點擊下一張、隨機洗牌、標記已學，全部儲存在本機瀏覽器。

## 本地使用

用瀏覽器打開 `index.html`（`file://`），一切運作於瀏覽器內，不需網路。

## Fork → Remix → Publish

1. Fork 此目錄
2. 替換預設單字清單、調整配色與版型
3. 發佈為靜態網頁（選做）

## 任務

### Level 1
- 替換預設單字清單
- 改變 primary 色

### Level 2
- 加入進度百分比條
- 新增匯出學習筆記按鈕

### Level 3
- 多組單字集可切換
- 按難易度篩選
