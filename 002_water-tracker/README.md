# 補水夥伴

純靜態、localStorage 儲存、不需要網路的每日補水追蹤 App。支援手機、平板與桌機 RWD；中央夥伴會隨有效補水進度由下往上顯色。

不同飲品會依記錄順序由下往上分層顯示，保留各自的飲品色彩，不會被最後一杯覆蓋。例如先喝 500 ml 紅茶（有效補水 450 ml），再喝 500 ml 水，角色會先顯示底部 22.5% 的紅茶色，再接續 25% 的水色，總進度為 47.5%。

飲品選擇列支援手機左右滑動、桌面滑鼠按住拖曳、觸控板水平捲動與鍵盤左右方向鍵。有效補水達到每日目標的 100% 時，分層剪影會淡出並顯示所選角色的全彩真面目；羊駝與長頸鹿使用專屬全彩插畫，貓頭鷹與松鼠則以使用者提供的角色為基礎重新輸出高解析透明圖與遮罩，在手機及桌面放大顯示時仍保持清晰。

角色選單中的奶泡（羊駝）、高高（長頸鹿）、珍珠（貓頭鷹）與阿松（松鼠）皆顯示全彩縮圖；單色遮罩只用於主畫面的補水進度填色。

## 本地使用
1. 打開 `index.html`。
2. 設定每日有效補水目標（預設 2000 ml）。
3. 選擇飲品與容量，確認畫面上的換算結果。
4. 點擊「記錄」加入今日進度；可撤銷上一筆或清空今日。
5. 點擊角色按鈕，可在奶泡、高高、珍珠與阿松之間切換。

## 飲品換算

- 水／氣泡水：100%
- 紅茶／綠茶／牛奶：90%
- 果汁：85%
- 咖啡：80%

例如 500 ml 紅茶會計入 450 ml 有效補水；若每日目標是 2000 ml，角色填色比例就是 `450 ÷ 2000 = 22.5%`。這些係數是方便日常記錄的估算，不是人體吸收的精密測量，也不能取代醫療建議。

## 資料儲存
- 當日飲品、實際容量與換算後補水量儲存於 `water-tracker:v1:date`。
- 目標儲存於 `water-tracker:v1:goal`。
- 選擇的補水夥伴儲存於 `water-tracker:v1:character`。
- 跨天自動歸零。
