# 分組隨機器

貼上人員名單（每行一名），輸入分組數，產生公平隨機分組：每人恰被分一次，組間人數差 ≤ 1。

## 本地使用

用瀏覽器打開 `index.html`（`file://`），一切運作於瀏覽器內，不需網路。

## Fork → Remix → Publish

1. Fork 此目錄
2. 替換預設範例名單、調整配色
3. 以靜態網頁託管工具發佈（選做）

## 任務

### Level 1
- 替換預設人名範例
- 改變主題色

### Level 2
- 加入分組驗證（每人至少某數）
- 新增多次重抽按鈕

### Level 3
- 儲存多份分組設定
- 以 CSV 匯出分組結果
