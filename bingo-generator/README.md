# Bingo 產生器

編輯 24 個格子內容，產生 5×5 賓果卡（中央為「免費」格）。隨機排布、可重擲、可列印。

## 本地使用

用瀏覽器打開 `index.html`（`file://`），一切運作於瀏覽器內，不需網路。

## Fork → Remix → Publish

1. Fork 此目錄
2. 改文字、配色、格子數
3. 以靜態網頁託管工具發佈（選做）

## 任務

### Level 1
- 修改預設字詞清單
- 更換主題色

### Level 2
- 增加格子數（例如 6×6）
- 新增匯出圖片按鈕

### Level 3
- 儲存多張卡片供切換
- 開啟檔案選取以載入自訂主題
