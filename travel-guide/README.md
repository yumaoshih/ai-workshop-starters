# 翻頁旅行手冊

一份可實際翻頁的七頁臺南旅行手冊。閱讀時，旁邊會同步顯示該頁的圖片生成提示詞；提示詞可以直接改寫並複製使用。

## 本地使用

直接用瀏覽器打開 `index.html` 即可。所有插畫與資料都放在本機，不需要網路或 API 金鑰。

支援的操作：

- 點擊上一頁／下一頁
- 點擊手冊左右頁緣
- 鍵盤方向鍵
- 按住書頁拖曳，或用觸控／滑鼠左右滑動；書頁會先跟著手勢移動再翻頁
- 編輯並複製每頁提示詞
- 從 47 個分類選項建立自己的行李清單
- 新增自訂項目、拖曳排序、勾選並保存清單

## Fork → Remix → Publish

1. Fork 此目錄。
2. 修改七頁的旅行內容與右側 `PROMPTS` 提示詞。
3. 替換 `assets/` 中的三張 WebP 本機插畫，或延伸為自己的城市手冊。
4. 發佈為靜態網站。

## 工作坊延伸

- Level 1：換成自己的目的地、行程與色彩。
- Level 2：替換水彩插畫、增加頁數或下載列印版本。
- Level 3：加入多本手冊選擇與本機行程收藏。
