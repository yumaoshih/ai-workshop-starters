# 旅遊指南

七頁旅遊指南，以本地靜態內容翻頁閱讀。含進度指示與可持續チェック列表（勾選事項跨重載保留）。不依賴任何遠端地圖。

## 本地使用

用瀏覽器打開 `index.html`（`file://`），一切運作於瀏覽器內，不需網路。介面支援鍵盤（左／右方向鍵）與觸控（左右翻頁區域）頁面切換。

## Fork → Remix → Publish

1. Fork 此目錄
2. 替換七頁內容與圖片（使用本地圖片或純文字）
3. 以靜態網頁託管工具發佈（選做）

## 任務

### Level 1
- 替換頁面文本與圖片
- 調整主題色

### Level 2
- 加入圖表／行程小提醒
- 新增列印行程功能

### Level 3
- 多條路線可選
- 本地行程儲存多份
