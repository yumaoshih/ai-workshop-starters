# 禁食時鐘

純靜態、localStorage 儲存、不需要網路的禁食計時工具。

## 本地使用
1. 打開 `index.html`（雙擊或 `file://` 路徑）。
2. 選擇 16 / 18 / 20 小時預設。
3. 點擊「開始」，可暫停與重置。

## 資料儲存
- 使用命名空間 `fasting-clock:v1` 的 localStorage。
- 含選中的預設、狀態、已累積毫秒數。

## Fork → Remix → Publish
1. Fork 此資料夾，修改色調與文字。
2. 不依賴外部資源，可直接改為獨立 HTML。
3. 如需發佈，另開 GitHub/Pages 流程（需額外審核）。

## Level 1–3 任務
- Level 1: 選預設並啟動計時。
- Level 2: 切換暫停與重置。
- Level 3: 調整預設時長與樣式。
