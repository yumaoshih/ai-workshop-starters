# 斷食小日子

純靜態、可離線使用的手機式斷食計畫 App。介面採米白方格紙與深藍手繪風格，資料透過 localStorage 保留。

## 功能
- 日計畫：13–11、15–9、16–8、18–6、20–4。
- 週計畫：溫和起步週、漸進挑戰週、16–8 穩定週。
- 選擇計畫後會顯示開始時間、斷食／進食時數與預計完成時間。
- 計時支援暫停、繼續、重置及結束確認。
- 重新整理後保留目前計畫與計時狀態。

## 本地使用
1. 直接打開 `index.html`，或在專案根目錄啟動靜態伺服器。
2. 點擊「選擇斷食計畫」。
3. 選擇日／週計畫並確認後開始計時。

## 資料儲存
- 使用命名空間 `fasting-clock:v1`，資料結構版本為 2。
- 舊版的小時預設會在讀取時自動轉換為對應日計畫。
