# 小小集點王

設定孩子名稱與獎勵清單，藉由新增／減少積分鼓勵日常行動。使用者可以在「冒險地圖」、「今日貼紙簿」與「家庭小商店」三種風格間切換；外觀會改變，但點數、獎勵與操作流程保持一致。

如積分不足，獎勵不可兌換；餘額也永遠不會低於零。所有設定與風格選擇只保存在目前瀏覽器。

## 本地使用

用瀏覽器打開 `index.html`（`file://`），一切運作於瀏覽器內，不需網路。

## Fork → Remix → Publish

1. Fork 此目錄
2. 替換預設獎勵，或設計自己的第四套主題
3. 以靜態網頁託管工具發佈（選做）

## 任務

### Level 1
- 修改色彩、文案與本機插畫，做出第四套主題
- 保留共用畫面結構與核心集點功能

### Level 2
- 完成獎勵新增、編輯、刪除與目標選擇
- 加入符合各主題的兌換回饋

### Level 3
- 增加孩子切換（多孩子）與點數歷史
- 匯入／匯出本機資料快照

完整畫面、主題與互動規則請參考 `DESIGN.md`。
