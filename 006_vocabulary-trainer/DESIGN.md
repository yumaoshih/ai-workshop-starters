# Word Lab 高頻英文單字遊戲 — 設計

## 產品原則

- 先保留原始資料，再建立可解釋的學習權重。
- 清楚區分「來源詞頻」與「官方出題機率」；後者不做無資料支持的宣稱。
- 完整字庫只載入一次，畫面一次只渲染目前卡片，避免 4,000 多筆資料造成 DOM 負擔。
- 個人進度、筆記與自訂單字分開保存，不把整份基礎字庫寫入 `localStorage`。
- 同時支援一般網頁、`file://` 本機使用與可安裝的 PWA；App shell 和完整字庫由 Service Worker 快取。
- 用短回合、連勝和 XP 降低背單字的枯燥感，但不以動畫或裝飾干擾讀字與作答。

## 核心遊戲回合

- 頂部只保留 Word Lab 品牌、連勝、XP 和設定入口，忠實對應選定的手機參考稿。
- 主遊戲依序呈現 10 題回合進度、全寬大型單字卡、圓形發音鍵、四個直向繁中選項與結果回饋。
- 答對即增加 XP、連勝和已學會收藏；答錯顯示正解並重置連勝。
- 桌面維持置中的手機遊戲框架，避免把核心回合重新擴成複雜工具畫面。
- 前後題、依權重抽題、收藏、詞頻與來源排名都收進設定；主畫面只聚焦四選一與「下一題」。
- 考試分類、搜尋、詞頻、發音引擎、筆記、自訂單字及授權統一收進設定對話框。

## 色彩

- `--paper: #fffdf8`：暖白紙張
- `--ink: #123f34`：深墨綠
- `--green: #0e614d`：主要操作色
- `--mint: #dcefe7`：單字卡與正確狀態
- `--yellow: #ecdf8d`：XP、連勝與焦點提示

## 發音

預設使用 Kokoro-82M q8 ONNX 模型，以模組型 Web Worker 及 WASM 在瀏覽器本機合成 WAV。模型延遲到第一次播放才載入，下載過程提供可存取的進度列。q8 固定使用 WASM，避免 Kokoro 官方不建議的 q8／WebGPU 組合產生不正確音訊；若未來改用 WebGPU，應同時改用官方建議的 fp32 模型。模型載入後可手動釋放工作執行緒與模型記憶體，瀏覽器 Cache API 中的模型快取保留。

第二引擎使用 Web Speech API 的 `SpeechSynthesisUtterance`。使用者可選 `en-US` 或 `en-GB`，也可從 `speechSynthesis.getVoices()` 回傳的英文聲音中指定實際 voice；介面會顯示 voice 名稱、語系及 `localService` 狀態。Kokoro 載入或產生失敗時自動回退到此引擎。

## 無障礙

- 卡片可用 Enter 或 Space 翻面。
- 左右方向鍵可切換卡片，`P` 可播放發音。
- 所有互動元件保留明顯 `focus-visible`。
- 進度、儲存結果與語音狀態使用 `aria-live`。
- 支援 `prefers-reduced-motion`。
