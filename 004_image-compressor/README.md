# 圖片瘦身站

完全在瀏覽器本機處理的批次圖片轉檔與壓縮 Starter；不會上傳圖片，也不需要 API、帳號或金鑰。

## 使用方式

1. 直接開啟 `index.html`。
2. 點擊或拖放 PNG、JPEG、WebP、GIF 圖片。
3. 選擇保留原格式，或統一轉成 JPEG、PNG、WebP。
4. 調整壓縮品質後執行轉檔與瘦身。
5. 比較原始／輸出大小與節省比例，個別或批次下載。
6. 使用「清除所有」移除目前工作區資料。

## 隱私與限制

- 圖片只在目前瀏覽器分頁中處理，不會傳送到伺服器。
- JPEG／WebP 品質控制依瀏覽器 Canvas 編碼能力而定；PNG 使用無損輸出。
- PNG 不保證一定縮小；複雜或已最佳化的圖片可能產生較大檔案。
- GIF 動畫不會保留動畫影格。
- 為避免佔滿瀏覽器儲存空間，工作區圖片不會跨重新整理保留；輸出格式與品質設定會保留。

## Fork → Remix → Publish

1. Fork 或複製此專案。
2. 修改標題、配色、預設品質或支援的輸出格式。
3. Commit 後使用 GitHub Pages 發布。
4. 發布後用自己的圖片實測下載結果，不要只看畫面。

## Level 1–3 任務

- **Level 1：**更換配色、標題與預設壓縮品質。
- **Level 2：**加入尺寸縮放或自訂檔名規則。
- **Level 3：**加入 ZIP 打包、壓縮前後預覽比較或 EXIF 保留策略。
