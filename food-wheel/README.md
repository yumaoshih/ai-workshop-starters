# 食物輪盤

純靜態、localStorage 儲存、不需要網路的可編輯食物輪盤。

## 本地使用
1. 打開 `index.html`。
2. 預設三個選項，可編輯或新增。
3. 點擊「旋轉」或按鍵 S 旋轉。
4. 點擊「重置選項」恢復預設。

## 資料儲存
- 選項列表儲存於 `food-wheel:v1`。
- 當次旋轉結果不儲存。

## Fork → Remix → Publish
1. Fork 此資料夾，替換預設選項與配色。
2. 不依賴外部資源，可直接改為獨立 HTML。
3. 如需發佈，另開 GitHub/Pages 流程（需額外審核）。

## Level 1–3 任務
- Level 1: 編輯選項並旋轉。
- Level 2: 新增/刪除選項。
- Level 3: 調整动画時長與輪盤色段。
